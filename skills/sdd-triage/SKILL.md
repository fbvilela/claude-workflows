# SDD Triage Orchestrator

You are an orchestrator that automates the first two phases of the SDD workflow for a GitHub issue.

## Input

Use the user's arguments/request provided when invoking this skill.

## Your Task

1. Parse the issue number from the input (URL or direct number)
2. Set up the worktree for isolated operations
3. Read the GitHub issue content
4. Spawn subagents sequentially to create PRD and Spec using the actual commands
5. Commit and push the artifacts
6. Post a summary comment to the GitHub issue

## Step 1: Parse Issue Number

Extract the issue number from the input. It can be:
- A full URL like `https://github.com/owner/repo/issues/123`
- Just a number like `123` or `#123`

Store the issue number for later use.

## Step 2: Worktree Setup

The worktree provides isolation - all file operations happen there, never in the main working directory.

**Worktree path:** `~/.claude/sdd-worktree`

Execute these steps:

```bash
# Check if worktree exists
if [ -d ~/.claude/sdd-worktree ]; then
  # Worktree exists - update it
  cd ~/.claude/sdd-worktree
  git fetch origin
  git rebase origin/master || git reset --hard origin/master
else
  # Create new worktree
  mkdir -p ~/.claude
  git worktree add ~/.claude/sdd-worktree origin/master
fi

# Create specs directory
mkdir -p ~/.claude/sdd-worktree/docs/specs
```

## Step 3: Read GitHub Issue

Use `gh` to fetch the issue content:

```bash
gh issue view {number} --json title,body,labels,url
```

Store this content - you'll need the title, body, and URL for the subagent prompts.

## Step 4: Spawn PRD Subagent (Sequential - Wait for Completion)

**IMPORTANT:** Wait for this subagent to complete before starting Step 5.

Spawn a subagent with `subagent_type: "general-purpose"` that invokes the actual PRD command.

### PRD Subagent Prompt

```
Your working directory is: ~/.claude/sdd-worktree

You have a GitHub issue to analyze:

**Issue #{number}:** {title}
**URL:** {url}
**Labels:** {labels}

**Description:**
{body}

Run the /fabio-sdd-create-prd command with the issue content and these flags:
- --auto (non-interactive mode)
- --output ~/.claude/sdd-worktree/docs/specs/{issue_number}-PRD.md

Invoke it like this:
/fabio-sdd-create-prd {issue_body_content} --auto --output ~/.claude/sdd-worktree/docs/specs/{issue_number}-PRD.md
```

---

## Step 5: Spawn Spec Subagent (Sequential - Only After PRD Completes)

**IMPORTANT:** Only start this after Step 4 completes successfully.

Spawn a subagent with `subagent_type: "general-purpose"` that invokes the actual Spec command.

### Spec Subagent Prompt

```
Your working directory is: ~/.claude/sdd-worktree

A PRD has been created at: ~/.claude/sdd-worktree/docs/specs/{issue_number}-PRD.md

Run the /fabio-sdd-create-spec command with the PRD path and these flags:
- --auto (non-interactive mode, make best-effort decisions)
- --output ~/.claude/sdd-worktree/docs/specs/{issue_number}-spec.md

Invoke it like this:
/fabio-sdd-create-spec ~/.claude/sdd-worktree/docs/specs/{issue_number}-PRD.md --auto --output ~/.claude/sdd-worktree/docs/specs/{issue_number}-spec.md
```

---

## Step 6: Git Operations (In Worktree)

After both subagents complete successfully:

```bash
cd ~/.claude/sdd-worktree
git checkout -B AI-Triage
git add docs/specs/
git commit -m "AI Triage for #{issue_number}: {issue_title}"
git push -u origin AI-Triage --force
```

## Step 7: Post GitHub Comment

Get the repository URL to construct the link to the spec file:

```bash
gh repo view --json url -q .url
```

Read the spec file to extract the overview and scope for the comment summary.

Then post a comment:

```bash
gh issue comment {issue_number} --body "$(cat <<'EOF'
## 🤖 AI Triage Summary

**Issue:** #{issue_number} - {issue_title}

### Proposed Approach
{2-3 sentence summary from spec overview}

### Scope
**Included:**
- {key items from spec}

**Excluded:**
- {what's NOT being done from spec}

### Full Specification
📄 [View PRD]({repo_url}/blob/AI-Triage/docs/specs/{issue_number}-PRD.md)
📄 [View Spec]({repo_url}/blob/AI-Triage/docs/specs/{issue_number}-spec.md)

---
⚠️ **Human review required** - This spec was auto-generated and may need adjustments.

🤖 Generated by Claude SDD workflow
EOF
)"
```

## Error Handling

- **If `gh` command fails:** Report the error to the user, don't create partial artifacts
- **If PRD subagent fails:** Report the error, don't proceed to Spec subagent
- **If Spec subagent fails:** Report the error, still attempt to commit/push the PRD if it exists
- **If git push fails:** Report the git error, note that spec files remain in worktree
- **If rebase fails:** Reset hard to origin/master and continue

## Final Report

After completion, report to the user:
1. PRD file path and status
2. Spec file path and status
3. Git branch and push status
4. GitHub comment status
5. Link to the GitHub issue

If any step failed, clearly indicate which step failed and why.
